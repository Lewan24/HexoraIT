# Dokumentacja HexoraIT

HexoraIT jest aplikacją SPA do dokumentowania infrastruktury IT, zasobów, sieci, incydentów, dokumentów, haseł i uprawnień organizacyjnych.

- Architektura: `architecture/`
- API: `api/`
- Bezpieczeństwo: `security/` i `audit/`
- Wdrożenie: `deployment/`
- Testy: `testing/`
- Instrukcja użytkownika i administratora: `user-guide/`, `admin-guide/`

Stan dokumentacji odpowiada kodowi na 2026-09-27. Elementy wymagające infrastruktury produkcyjnej są oznaczone jako zalecenia lub blokery właściciela.
