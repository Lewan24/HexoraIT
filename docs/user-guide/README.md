# Instrukcja użytkownika

Po zalogowaniu wybierz organizację i korzystaj z modułów zależnych od przyznanych uprawnień: zasoby, kontakty, grupy, sieci, projekty, zadania, incydenty, baza wiedzy, licencje, plany, dokumenty, pliki, diagramy, dashboard i sejf haseł.

Pliki dodawaj wyłącznie w obsługiwanych formatach i w limitach widocznych w formularzu. Ujawnienie hasła z sejfu jest operacją audytowaną. Brak uprawnienia lub cofnięcie członkostwa powoduje odrzucenie operacji przez API.
